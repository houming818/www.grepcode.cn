# GrepCode：TreeHeap 开放研究现场

> “代码是机器的诗，诗是灵魂的代码。”

欢迎来到 **GrepCode.cn**。这里持续公开 TreeHeap 的研究过程：一种以递归树堆、多分辨率状态、卷积 Kernel 和私有编解码协议为核心的实验性 AI 架构。

我们不把探索过程整理成事后必然成功的故事。每个重要结论都尽量保留 claim、predict、proof、evidence、反证条件和失败原因，让读者能够检查“代码是否真的实现了文章所说的 TreeHeap”。
